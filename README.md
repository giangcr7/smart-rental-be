# Smart Rental Backend

Backend API for a boarding house management system.

This project is built using **NestJS** and provides RESTful APIs for managing tenants, rooms, contracts, and other rental-related data.
The system uses **PostgreSQL** for data storage and **Prisma ORM** for database access.

---

## Tech Stack

* Node.js
* NestJS
* TypeScript
* PostgreSQL
* Prisma ORM
* Docker

---

## Project Structure

```
src/        application source code
prisma/     database schema and migrations
docker-compose.yml
```

---

## Features

* RESTful API built with NestJS
* Modular backend architecture
* PostgreSQL relational database
* Database access using Prisma ORM
* Docker configuration for running services locally

---

## Installation

Clone the repository

```
git clone https://github.com/giangcr7/smart-rental-be.git
```

Install dependencies

```
npm install
```

Run development server

```
npm run start:dev
```
